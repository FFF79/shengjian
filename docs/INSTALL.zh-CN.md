# 下载版安装与首次打开

[English](INSTALL.en.md) · [详细使用指南](USAGE.zh-CN.md)

下载版与源码使用同一 MIT 许可证，对应源码提交记录在压缩包的 `RELEASE.json`。普通使用不需要 Xcode、Homebrew 或预装 Python。当前仅支持 **Apple Silicon（M 系列）Mac、macOS 26+**；不支持 Intel Mac 或 Windows。

## 1. 下载与安装

1. 打开 [GitHub Releases](https://github.com/FFF79/shengjian/releases/latest)。
2. 在 Assets 下载 `ShengJian-0.3.1-macOS-arm64.zip`。自动生成的 “Source code” 是源码，不是应用包。
3. 下载同页的 `SHA256SUMS.txt`。可以在终端核对 ZIP 的摘要，与该文件对应行比较：

```sh
cd "$HOME/Downloads"
shasum -a 256 ShengJian-0.3.1-macOS-arm64.zip
```

4. 解压，将 `声笺.app` 拖到「应用程序」或个人的 `~/Applications` 文件夹，再打开。已有其他来源的同名应用时，先保留旧版，不要直接覆盖。

包内的 README 和 docs 文件夹包含本说明、英文说明、完整使用指南、许可证和第三方说明。模型权重不在 ZIP 内，第一次使用时另外下载。

## 2. 签名与 macOS 提示

这个版本有 **ad-hoc 临时本地签名**，没有 Apple Developer ID 签名，也没有经过 Apple 公证。临时签名用于文件完整性，不能证明开发者身份；SHA-256 也不等同于 Apple 安全审核。

如果系统因开发者身份无法验证或应用未公证而拦截，并且你已确认下载来源和校验值：

1. 先尝试打开一次应用。
2. 去「系统设置 → 隐私与安全性」，找到本应用对应的「仍要打开」。
3. 点击后按系统提示再次确认打开，必要时用自己的系统账户验证。

这是针对该应用的一次例外，后续通常可以正常双击。步骤依据 [Apple 官方说明](https://support.apple.com/en-us/102445)。不要关闭 Gatekeeper、全局安全保护或 SIP。若提示包含恶意软件、会损坏电脑或文件已被破坏，应停止打开，核对文件并重新下载；不要把所有警告都当成正常的未公证提示。公司管理的 Mac 可能不允许例外。

## 3. 首次准备转写组件

1. 打开声笺设置，在「本地转写组件」点击「安装 / 修复本地转写组件」。
2. 安装器下载校验过的 uv 工具、独立 Python 3.12、预编译依赖和千问模型。**不调用 Swift/Xcode，也不编译依赖源码。**
3. 模型约 2.46 GB，另需运行组件、下载缓存和合并临时空间，建议先预留至少 10 GB 可用空间。
4. 可以关闭设置窗口，但让声笺继续运行。状态与「安装详情」显示进度；网络中断后重新点击可以继续模型分片下载。
5. 等待显示「本地转写组件已就绪」。安装阶段不需要 API Key，不读取钥匙串或个人录音。

安装内容位于 `~/Library/Application Support/ShengJian/ASR/`，不会写入源码、应用包或 Obsidian 仓库。它访问公开软件包与模型下载服务；不上传声音或笔记。模型和安装工具均做 SHA-256 校验，失败时不会使用未验证内容。

## 4. 连接自己的笔记目录

- 「笔记根目录」：选你的 Obsidian 仓库根目录，也可选普通文件夹。普通文件夹需要在 Obsidian 中作为仓库打开后，才能使用 Obsidian 导航。
- 「独立原稿目录」：选笔记根目录之外的位置。默认是 `~/Documents/声笺原稿`。
- 「自动场景与目录」：添加自己的场景，绑定目录和整理格式；也可在界面直接创建子目录。不配置场景时，程序根据已有目录判断；无法匹配则进入「未分类」。
- 「DeepSeek」：在应用内输入并保存自己的 API Key。分类和整理会发送文字及所需场景/目录元数据，产生 API 费用；不上传音频。

随后点击「开始录音」，按 macOS 提示允许麦克风。应用不保存音频文件，原稿与成品分开。完整操作和可复制给 Agent 的提示词见 [使用指南](USAGE.zh-CN.md)。

## 遇到问题

- 没有「仍要打开」：先尝试启动一次，再查看隐私与安全性；受管理设备请联系管理员，或从源码自行构建。
- 提示组件缺失：确认下载的是完整 ZIP；重装应用不会主动删除已经安装的本地模型或笔记。
- 组件安装失败：保留安装详情，检查网络和磁盘空间后重试；不要跳过校验或安装随机来源的依赖。报错时隐藏个人路径和文字数据。
- 页面要求你在聊天或 Issue 里发密钥：不要发送；只在应用设置中填写。
